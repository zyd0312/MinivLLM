## 建议版本 A：强调学习与代码贡献（适合实习）

**项目名称：** vLLM 推理引擎深度学习与优化实践

**项目描述：**
深入学习 vLLM 推理引擎原理，通过阅读源码、重构核心模块，系统掌握了大模型推理的关键技术。对 12 个核心文件贡献 2700+ 行代码，重点优化了注意力机制与调度逻辑。

**核心工作：**

1. **Triton 注意力算子实现与优化：** 
   - 使用 OpenAI Triton 实现了 FlashAttention (Prefill 阶段) 和 PagedAttention (Decode 阶段)
   - 理解并实现了 Online Softmax、Block-Sparse Attention、KV Cache 分页管理等核心算法
   - 通过 benchmark 对比了 PyTorch 原生实现、Naive Triton、FlashAttention 的性能差异

2. **推理引擎架构深度理解：**
   - 重构了 Scheduler、BlockManager、ModelRunner 等核心模块，理解 Continuous Batching 的调度逻辑
   - 实现了基于 Sequence 的请求管理、KV Cache 块分配与回收机制
   - 支持 Llama 3.2 和 Qwen 系列模型的完整推理流程

3. **模型层优化与工程实践：**
   - 优化了 RoPE、RMSNorm、Linear 等基础算子的实现
   - 添加了详细的中文注释（12 个文件共 2700+ 行修改），提升代码可读性
   - 编写了 Prefill 和 Decode 阶段的性能基准测试脚本
