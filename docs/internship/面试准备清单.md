# 面试准备清单

## 一、必须能回答的技术问题

### 1. FlashAttention 原理
- **核心优化点：** Online Softmax 算法，通过分块计算避免存储完整的注意力矩阵
- **显存优化：** 从 O(N²) 降低到 O(N)，N 是序列长度
- **具体实现：** 在 `src/myvllm/layers/attention.py:147` 的 `flash_attention_varlen_kernel`
- **关键参数：** BLOCK_M, BLOCK_N（Tiling 大小）

### 2. PagedAttention 原理
- **核心思想：** KV Cache 按块分页存储，类似虚拟内存
- **Block Table：** 维护逻辑块到物理块的映射
- **优势：** 减少显存碎片，支持动态序列长度
- **具体实现：** 在 `src/myvllm/layers/attention.py:386` 的 `paged_attention_decode_kernel`

### 3. Continuous Batching
- **与 Static Batching 的区别：** 不需要等待整个 batch 的所有序列都完成
- **动态调度：** 序列完成后立即释放资源，新请求可以立即加入
- **实现位置：** `src/myvllm/engine/scheduler.py`
- **关键指标：** TTFT (首 token 延迟), TBT (token 间延迟), 吞吐量

### 4. KV Cache 管理
- **Block Manager：** 负责物理块的分配与回收
- **引用计数：** 支持多个序列共享相同的 KV Cache（Prefix Sharing）
- **实现位置：** `src/myvllm/engine/block_manager.py`
