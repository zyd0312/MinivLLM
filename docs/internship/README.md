## 💡 核心建议

### 做项目时：
- **一个方向做扎实 >> 三个方向做一半**
- **有真实 Benchmark 数据很重要**
- **每天记录进展，遇到的问题和解决方案**
- **代码加详细注释，展示你的理解**

### 写简历时：
- **只写你真正做过的事情**
- **用数据说话（显存降低 X%，速度提升 Y%）**
- **强调学习过程，不要夸大成果**

### 面试时：
- **诚实 > 一切**
- **不会的坦诚说"还在学习"**
- **展示你的学习能力和工程习惯**
